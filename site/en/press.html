journali in one sentence

journali is a PIM system for manufacturers and retailers that shows which product data is still missing for shop, catalogue and Digital Product Passport, allows maintenance as fast as in a spreadsheet and publishes the data checked to every channel.

journali in three sentences

journali is a product information management (PIM) system for manufacturers and retailers who want to maintain their product data in one place. It stores every change as a numbered entry with author and time in a journal and overwrites nothing – earlier states stay available, and versions freeze the documents delivered for a state. Checks for the Digital Product Passport, the Packaging and Packaging Waste Regulation (PPWR) and environmental claims (EmpCo) show gaps before publication; AI can be connected with the team's own key, and without a key the plugins work rule-based.

Facts

  • Type: PIM system (product information management) for manufacturers of technical products, retailers with variants, IT departments and agencies.
  • Name: “journali PIM” is a trademark filed with the German Patent and Trade Mark Office (DPMA).
  • Status: pre-release · 2026. Until the production release, journali is provided as a test version solely for testing and evaluation; the descriptions on journali.de refer to the production release.
  • Licence: GNU Affero General Public License, version 3 (AGPL-3.0), an open-source licence. The source code has been public since 22 October 2026. Other licence terms are available on request; the name “journali PIM” is not covered by the licence.
  • Publication: source code on GitHub (journalipim/journali), image ghcr.io/journalipim/journali public. Templates for Unraid (journali, database, product advisor) have been submitted to the Community Applications; the review is pending.
  • Operation: Docker package (Docker Compose) with PostgreSQL 18, or an app on Unraid, self-hosted. Media are stored in Postgres, in the file system or in S3-compatible object storage; changing is a copy run.
  • Technology: server with ASP.NET Core (.NET 8), interface with Vue 3; extensions as plugins that are replaced without a new image.

Key points

  • Journal and traceability: values, names, assignments, releases and the data model are entries in the journal; the state at any point in time can be restored.
  • Versions: a version is a pointer to the journal state of a product plus the delivered documents – immutable, with a retention period, can be withdrawn but not deleted.
  • Editing like in a spreadsheet: editing in the cell, keyboard through the list and bulk editing with range selection, fill and paste from the clipboard.
  • Digital Product Passport (ESPR), PPWR, EmpCo: check rules as plugins map data points, show gaps and check whole subtrees.
  • ETIM and GS1 GPC: assign classes, map characteristics to own attributes, see completeness per class; output as ETIM BMEcat.
  • AI with the team's own key: the team chooses the provider and brings its own key, which lies with the server; every suggestion is accepted, changed or discarded and appears with its author in the journal.
  • Product advisor with MCP: a chat window for the website answers from the products of a publication tree, also without AI; AI agents ask the same questions over MCP. Form of address and tone of the AI texts are adjustable, the AI can use own sources over MCP, and logged-in customers see their own view with a proof signed by the shop. The service runs in its own container, also on Unraid.
  • journali advisor: an assistant for using journali answers how, where and why questions from the help, names places in the interface as links and gives the reasons from the data of a node.
