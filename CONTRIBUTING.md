# Contributions

The source of journali is published under the GNU Affero General Public License, version 3 ([LICENSE](LICENSE)). There is
one contributor; the rights to the source lie with the licensor.

- **Pull requests are not accepted.** Each one is closed with a notice (`.github/workflows/pull-requests.yml`).
- **Code from issues and discussions is not taken over.** Describe a bug or a suggestion — what happens, what was expected,
  how to reproduce it — instead of sending code or a patch.
- **Extensions are plugins.** A third-party plugin is its publisher's own work and responsibility. The journali seal and
  catalogue cover journali's own plugins only ([docs/plugins-zertifizierung.md](docs/plugins-zertifizierung.md)).

Questions go to the Discussions. More about journali: [journali.de](https://journali.de).

## Beiträge (deutsch)

Der Quelltext von journali steht unter der GNU Affero General Public License, Version 3 ([LICENSE](LICENSE)).
Es gibt einen Beitragenden; die Rechte am Quelltext liegen beim Lizenzgeber.

- **Pull Requests werden nicht angenommen.** Jeder wird mit einem Hinweis geschlossen (`.github/workflows/pull-requests.yml`).
- **Code aus Issues und Discussions wird nicht übernommen.** Ein Fehler oder ein Vorschlag wird beschrieben — was
  geschieht, was erwartet war, wie es sich nachstellen lässt —, nicht als Code oder Patch geschickt.
- **Ergänzungen sind Plugins.** Ein Plugin Dritter ist ein eigenes Werk unter eigener Lizenz, und für es steht sein
  Herausgeber ein. Siegel und Katalog von journali gelten nur Plugins von journali
  ([docs/plugins-zertifizierung.md](docs/plugins-zertifizierung.md)).

Fragen gehören in die Discussions.
