# Tastatur

## Leiste

| Kürzel | Ansicht |
|---|---|
| Alt+1 | ▣ Baum |
| Alt+2 | ≡ Journal |
| Alt+3 | ⊞ Modell |
| Alt+4 | ⇩ Import |
| Alt+5 | ▨ Medien |
| Alt+6 | ⚙ Einstellungen |
| Alt+7 | ⬡ Plugins |
| Alt+8 | ⇶ Publikation |
| Alt+9 | ⚑ Aufgaben |

Die Leiste lässt sich durch Ziehen umsortieren; jedes Plugin kann ein- oder ausgeblendet werden.

## Baum

| Taste | Wirkung |
|---|---|
| ↑ ↓ | Knoten wechseln |
| ← → | zu- und aufklappen |
| / | Suche |
| Entf | Knoten zurückziehen, mit allem darunter |
| Strg+Klick | zur Auswahl dazu oder weg |
| Shift+Klick | Bereich wählen |
| Esc | Auswahl aufheben |
| Ziehen | umhängen; mit Shift verknüpfen |

## Knoten

| Taste | Wirkung |
|---|---|
| Tab | nächste Zelle |
| Enter | bearbeiten und speichern |
| Esc | verwerfen |
| Entf | eigenen Wert löschen |
| Strg+Enter | im grossen Editor speichern |
| Strg+Z, Strg+Y | Stapel rückgängig, wiederholen |
| Strg+B, Strg+I | fett, kursiv im Editor |

## Tabelle

| Taste | Wirkung |
|---|---|
| F2, Doppelklick | bearbeiten |
| Strg+A | alle Zeilen |
| Strg+D | füllen nach unten |
| Strg+Shift+D | Reihe fortsetzen |
| Strg+C, Strg+V | kopieren, einfügen, auch mit Excel |
| Strg+H | suchen und ersetzen |
| Strg+S | speichern |
| Strg+− | Zeilen zum Löschen vormerken |
| Shift+Leertaste | Zeile der Zelle markieren |

## Medien

| Taste | Wirkung |
|---|---|
| Strg+A | alle sichtbaren wählen |
| Esc | Auswahl aufheben |
| Ziehen auf einen Ordner | verschieben |

## Überall

| Taste | Wirkung |
|---|---|
| Esc | Dialog, Menü, Hilfe oder Editor schliessen |
| Enter | den einen Knopf eines Dialogs |
| ↑ ↓ Enter | im Kontextmenü wählen, Buchstabe springt |
