# Release and publication

Between maintenance and output are two steps: the **release** of a variant per channel and language, and the **publication tree**, which determines what goes out in which structure.

## Completeness

Which attributes are required is in the model per channel and language. At the node, ✓ Releases shows what is missing for each channel. Inherited values count if the attribute is inheritable; multi-value attributes need at least one row. A value that comes only from the master does not count as a translation.

## Release

The variant is released, per channel and optionally per language. If required values are missing, the release is rejected and names what is missing. A release can be revoked. The status discontinued at the product overrides every release below.

A workflow can trigger the release as the effect of a step; the step then checks beforehand whether it can proceed.

## Publication tree

Under ⇶ Publication there is one tree of **rubrics** per channel, optionally per market. Product groups and products of the maintenance tree are dragged in: as a **reference** that follows the maintenance tree, or as a **copy** of the structure that can be freely restructured. A rubric carries its own texts and images like every node, and a display name that applies only here.

**Rules** fill a rubric automatically: by name or by attribute value, flat or structured by the product group above.

A product is published when a variant is released for the channel and the tree's market is among the product's markets; empty means everywhere. The view shows what is published, what is held back and why, and which products are not yet sorted in.

## Freezing a state

A rubric can be frozen to a journal state: the publication then reads the maintenance as of that moment until the state is updated or released. Nothing is copied, it is a pointer into the journal.

## Versions

A version freezes the state of a node and attaches the documents that went out with it: data sheet, safety data sheet, catalogue page, generated by the generator plugins. A version has a retention period, can be retired but not deleted, and shows the difference between then and now. Rolling back sets the values from then as a new batch.
