# Keyboard

## Rail

| Shortcut | View |
|---|---|
| Alt+1 | ▣ Tree |
| Alt+2 | ≡ Journal |
| Alt+3 | ⊞ Model |
| Alt+4 | ⇩ Import |
| Alt+5 | ▨ Media |
| Alt+6 | ⚙ Settings |
| Alt+7 | ⬡ Plugins |
| Alt+8 | ⇶ Publication |
| Alt+9 | ⚑ Tasks |

The rail can be reordered by dragging; every plugin can be shown or hidden.

## Tree

| Key | Effect |
|---|---|
| ↑ ↓ | change node |
| ← → | collapse and expand |
| / | search |
| Del | retire node with everything below |
| Ctrl+click | add to or remove from the selection |
| Shift+click | select a range |
| Esc | clear selection |
| drag | move; with Shift link |

## Node

| Key | Effect |
|---|---|
| Tab | next cell |
| Enter | edit and save |
| Esc | discard |
| Del | delete own value |
| Ctrl+Enter | save in the large editor |
| Ctrl+Z, Ctrl+Y | undo, redo a batch |
| Ctrl+B, Ctrl+I | bold, italic in the editor |

## Table

| Key | Effect |
|---|---|
| F2, double-click | edit |
| Ctrl+A | all rows |
| Ctrl+D | fill down |
| Ctrl+Shift+D | continue series |
| Ctrl+C, Ctrl+V | copy, paste, also with Excel |
| Ctrl+H | find and replace |
| Ctrl+S | save |
| Ctrl+− | mark rows for deletion |
| Shift+Space | select the row of the cell |

## Media

| Key | Effect |
|---|---|
| Ctrl+A | select all visible |
| Esc | clear selection |
| drag onto a folder | move |

## Everywhere

| Key | Effect |
|---|---|
| Esc | close dialog, menu, help or editor |
| Enter | the one button of a dialog |
| ↑ ↓ Enter | choose in the context menu, a letter jumps |
